# Лендинг марафона «Карьера»

Отдельная страница со своими стилями, от `css/` основного сайта не зависит.
Опубликована на **https://dariyap.ru/marathon/**, деплой автоматический
при пуше в `main`.

```
marathon/index.html     страница целиком: разметка и стили
marathon/apps-script.gs код для Google-таблицы (на сайте не используется)
js/marathon.js          тексты программы, FAQ, интерактив
assets/marathon/        фотографии ведущих
```

Тексты программы и FAQ лежат в начале `js/marathon.js`.

> **Никаких секретов в `js/marathon.js`.** Файл открыт любому посетителю
> через F12 и лежит в публичном репозитории. Секретный ключ ЮKassa,
> секретное слово и пароли — только в Apps Script, на серверах Google.

## Заявки и оплата — в телеграм-боте

Формы на странице больше нет. Все кнопки ведут в **@students_community_bot**:
он рассказывает о комьюнити, показывает тарифы, принимает оплату прямо внутри
Telegram (ЮKassa работает провайдером за кадром) и сам впускает оплатившего
в закрытый чат — сверяя постучавшегося со своей базой оплат.

Код бота лежит в отдельном проекте, не в этом репозитории: там платёжные
токены, которым нельзя попадать в публичный репозиторий сайта.

Метки на кнопках видны в логах бота — по ним понятно, откуда пришёл человек:

| Кнопка | Метка |
|--------|-------|
| «Хочу в первый поток» (первый экран) | `site_hero` |
| «Занять место», 1 месяц | `site_month` |
| «Занять место», 3 месяца | `site_quarter` |
| «Вступить в комьюнити» (финал) | `site_final` |

### Что осталось от прежней схемы

`marathon/apps-script.gs` и Google-таблица лендингом больше не используются —
файл сохранён на случай, если заявки понадобится собирать снова. Как была
устроена форма (почта через FormSubmit, оплата через платёжную форму ЮKassa,
связка заявки с платежом по `customerNumber`) — смотрите в истории git,
до коммита, который убрал форму.

## Локальный запуск

```bash
python -m http.server 8080
```

Открывать через `http://localhost:8080/marathon/`, а не файлом с диска:
из `file://` форма работать не будет.
